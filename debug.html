Debug launcher

Test any part of the experiment without running the whole thing. Runs started here use debug mode: no device check, nothing is uploaded unless you tick "Upload", a label in the corner shows the current step, F2 skips the rest of the current step, and the end screen shows the data file (with a Download button). The real study is index.html; settings are in js/config.js, wording in js/texts.js.
